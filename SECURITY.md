# Security Policy

## Supported versions

Only the latest release of GabeTeX receives security fixes. Before you report a problem, please check that it happens on the [latest release](https://github.com/gabe-rbo/GabeTeX/releases/latest). All releases are listed on the [Releases page](https://github.com/gabe-rbo/GabeTeX/releases).

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or discussions. Report them privately instead:

1. Open the [Security tab](https://github.com/gabe-rbo/GabeTeX/security) of the repository.
2. Click **Report a vulnerability** and fill in the form.

This uses GitHub's private vulnerability reporting, so only the maintainer can read your report until a fix is ready.

### What to include

- The GabeTeX version and your macOS version
- What the problem is, and what someone could do with it
- Steps to reproduce it, plus a minimal project or file if one is needed
- Any proof-of-concept code, with a short note on what it does

### Privacy note

GabeTeX runs TeX locally on your computer and never sends your documents anywhere. A report therefore usually concerns the app itself, such as how it runs TeX tools or how it reads and saves your files.

### What to expect

The maintainer aims to acknowledge a report within 7 days, and will keep you informed while the problem is investigated and fixed. GabeTeX is maintained by one person in their spare time, so please allow for some delay.
