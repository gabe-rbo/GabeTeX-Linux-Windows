# Contributing

Thanks for your interest in GabeTeX for Linux & Windows.

## Before you start
- For anything larger than a small fix, open an issue first to discuss it.
- Read [INSTRUCTIONS.md](INSTRUCTIONS.md) for the branch flow, the layout, the tests and packaging.

## Pull requests
- Branch from `main` and open the pull request against `main`.
- Keep pull requests focused on one change.
- Update `CHANGELOG.md` under `Unreleased` for user-visible changes.
- Use short, imperative commit messages (for example, `Add PDF preview toolbar`).

## Conduct and security
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md), not in public issues.
